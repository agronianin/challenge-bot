# Приватные данные

Все реальные секреты, адреса серверов, SSH targets, приватные идентификаторы, данные пользователей, дампы и материалы упражнений хранятся только в игнорируемой `.local/`. В Git — инструкции, код и шаблоны с заполнителями. Не выводи приватные значения в чат, логи проверок, diff или PR.

| Путь внутри `.local/` | Назначение |
| --- | --- |
| `runtime.env` | Переменные запуска: токен, параметры БД, настройки бота |
| `servers.md` | Адреса окружений, SSH targets и частные заметки об эксплуатации |
| `config/` | Внешние runtime-конфиги и локализации |
| `datasets/exercises/` | Рабочий CSV, видео и приватная разметка стартового набора |
| `backups/` | Резервные копии БД и данных |
| `logs/` | Логи приложения, содержащие SQL и параметры |
| `verification/` | Локальные отчеты проверок, контрольные суммы и временные результаты |

Создавай только нужные файлы. Для `.local/` используй права `700`, для файлов секретов — `600`. Шаблон переменных — `.env.example`; порядок запуска — [scripts/README.md](../scripts/README.md). Приватный набор данных — [datasets/README.md](../datasets/README.md).

`.local/` исключена и из Git, и из Docker build context. В контейнер монтируются только нужные подкаталоги; миграции не получают весь рабочий каталог. Не обходи исключения через `git add -f` и не копируй приватные данные в тестовые fixtures. Для примеров используй вымышленные данные.

Перед коммитом проверяй индекс и diff по [правилам Git](GIT.md). `.gitignore` не удаляет уже отслеживаемые файлы и прежние коммиты. При обнаружении утечки не печатай значение: укажи файл/тип, исключи из будущих коммитов, согласуй очистку опубликованной истории и замену секрета.

Git не резервирует `.local/`: сохраняй ее защищенную копию вне компьютера/VPS и переноси отдельно от clone. Не перезаписывай существующие файлы при восстановлении; проверяй контрольные суммы данных. Папка не является шифрованием и не заменяет резервное копирование.
