# Стартовый набор упражнений

Приватный рабочий набор расположен в `.local/datasets/exercises/`: `exercises.csv`, `videos/`, `README.md` с текущими замечаниями. Для будущей разметки используй `annotations/`, для исходных записей — `sources/` внутри этого же каталога. Эти данные не входят в clone; перенос и резервирование — [правила приватных данных](../docs/PRIVATE-DATA.md).

## CSV и импорт

UTF-8 с заголовками:

```text
name,type_name,base_reps,is_static_reps,static_reps,reps_unit,enabled,selection_group,video_path,comment
```

- `name`, `type_name`, `base_reps`, `is_static_reps`, `static_reps` обязательны. Числа — целые неотрицательные; для boolean используй `true/false`.
- Несколько типов разделяются `;` (также принимается `|`); неизвестные типы создаются автоматически.
- `reps_unit`: `repetitions` или `seconds`, по умолчанию `repetitions`.
- `enabled` необязателен: при отсутствии/пустом значении сохраняется прежнее, для нового упражнения — `true`.
- `selection_group`, `video_path`, `comment` могут быть пустыми; отсутствие этих колонок при обновлении очищает соответствующие значения.
- Импорт обновляет по имени, включая типы. Переименование создает другую запись; удаление строки не удаляет запись из БД. Для исключения из подбора используй `enabled=false`.
- `file_id` импортом не сбрасывается: после смены видео может отправляться старый кеш. До исправления нужна осознанная очистка соответствующего `file_id` в БД.

Импорт: «Администрирование → Импорт CSV упражнений», CSV отправляется как Telegram document. Видео эта операция не загружает: каталог `videos/` нужно отдельно передать на сервер. Compose монтирует его в `/app/videos:ro`, поэтому CSV хранит относительные пути `./videos/...`. Отсутствующее видео заменяется текстом задания.

Перед загрузкой проверь обязательные поля, уникальность имен, существование видео и точное совпадение Unicode-имен на Linux. Проблемы конкретных клипов, происхождение и временные интервалы нарезки записывай только в приватный README/разметку набора. Не повторяй нарезку уже исправленных файлов без визуальной проверки.
