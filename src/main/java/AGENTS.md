# Java-код

- Используй Java 25 и корневой `./mvnw` (Maven 3.9.14). Явные типы обязательны, `var` не используй.
- Разделяй обязанности по пакетам: `service`, `model`, `model.type`, `repository`, `config`. Не создавай корневой пакет `bot`, пустые пакеты и слои без задачи. При переносе обновляй package, импорты, конфигурацию, callers и расположение тестов.
- Перед изучением или изменением Telegram-flow читай [service/bot/AGENTS.md](su/msk/nlx2/challengebot/service/bot/AGENTS.md).
- Лимит строки — 150 символов с отступом. Помещающиеся вызовы и объявления оставляй одной строкой; иначе весь список нескольких аргументов/параметров переноси: каждый на своей строке, закрывающая скобка отдельно.
- Не строй лестницу обёрток с одним аргументом: объединяй начала и закрытия вложенных вызовов; длинные цепочки переноси перед точкой. Не дроби короткие вложенные вызовы ради переноса внешнего.
- Не добавляй лишние пустые строки внутри методов и в конце файлов. Для `Object...` не создавай ненужный массив.
- Перед планированием или изменением тестов читай [правила тестов](../../test/AGENTS.md).
